🎯 About the Game

Python Hangman is a fun and interactive learning game designed to help students learn Python concepts through questions and Hangman gameplay.

📝 Syntax — Python syntax

🎮 How to Play

1️⃣ Select a category.

2️⃣ Choose a level.

3️⃣ Read the question.

4️⃣ Enter your answer.

5️⃣ Correct answers earn points.

6️⃣ Wrong answers reduce your chances.

7️⃣ Use hints when needed.
